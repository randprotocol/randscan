# randscan.org in sixteen languages — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve every randscan.org page in English at `/…` and in fifteen more languages at `/{code}/…`, send a first-time visitor to `/` to their country's language from an offline IP lookup, and let a cookie set by a language menu win from then on.

**Architecture:** All pages move under `src/app/[lang]/`; a Node-runtime middleware rewrites unprefixed paths into the English tree, redirects `/` by country, and adds `hreflang` `Link` headers. One JSON dictionary per language, English deep-merged underneath, reaches client components through a context provider and a `useT()` hook; formatters take the page's locale. A script translates the English dictionary with `claude -p`; tests pin parity and the routing rules.

**Tech Stack:** Next.js 15.5 (app router, standalone output, Node middleware), React 19, Tailwind 3.4 (logical utilities, `rtl:`), `mmdb-lib` (pure-JS MaxMind reader) over DB-IP Country Lite, `node --test` for tests, `claude -p` for translation.

**Spec:** `docs/superpowers/specs/2026-10-02-explorer-i18n-design.md`

## Global Constraints

- Codes, in this order everywhere: `en ru zh zh-hk ko id ms ja ar fa es pt de fr it pl`. Tags: `en ru zh-Hans zh-Hant-HK ko id ms ja ar fa es pt de fr it pl`. `ar` and `fa` are `rtl`.
- English is served unprefixed; `/en/…` is a 308 to the unprefixed path. No existing English URL changes.
- The country lookup runs only for exactly `/` with no valid `lang` cookie, in process, from `GEOIP_DB`; nothing is stored or sent. Missing database = English.
- The cookie is `lang`, path `/`, `Max-Age` 31536000, `SameSite=Lax`; set only by the switcher.
- The country table is the spec's and identical to randprotocol.org's.
- API error strings are shown as received (English). Hashes, addresses, amounts and code are `dir="ltr"`.
- Numbers and dates use `Intl` with the locale's tag; no `'en-US'` literal remains in `src/`.
- Glossary kept in English in every language: Rand, RAND, zUSD, RPL, Rand Wallet, RandScan, randscan, STARK, FRI, zkVM, RISC-V, HotStuff, ML-KEM, USDT, USDC, Solana, Tron, Ethereum, Binance Smart Chain, testnet, mainnet-beta, API, WebSocket, JSON-RPC, and every identifier, field name and RPC method.
- The header stays compact: the language menu is one icon button in the right-hand group (memory: randscan-ui-preferences). Accent only for state; links stay `text-strong`.
- Commit after every task; never reformat untouched files.

## Review Focus

1. A request for `/` carrying `lang=xx` where `xx` is not a known code (a stale or forged cookie) must be treated as no cookie: the country decides, and the bad value is not echoed anywhere. Test in Task 2 (`decide` with cookie `'xx'`).
2. `X-Forwarded-For` with several addresses (`client, proxy`) or an IPv6 client: the first address is used, trimmed; a malformed address never throws and yields English. Test in Task 3 (`countryOf('not an ip')`, `clientIp('1.2.3.4, 10.0.0.1')`).
3. A path that merely starts with a code's letters (`/idle`, `/zhang`, `/arbitrary`) is not a locale prefix; `/id` and `/id/` are. Test in Task 1 (`localeFromPath('/idle') === 'en'`).
4. A translation file missing a whole page's subtree, or an array shorter than English, must render the English text for the gap rather than `undefined`; a translation that drops a `{placeholder}` fails the parity test, not the page. Tests in Task 4 (`getMessages` deep merge) and Task 10 (parity).
5. Right-to-left pages: a hash or amount inside an Arabic sentence must keep its digits and hex in reading order, and the search box's icon must sit at the start edge. Checked visually in Task 11 on `/ar/` and `/ar/blocks`; pinned by `dir="ltr"` on `.font-mono` in Task 5.

```js
  { code: 'es', tag: 'es', name: 'Español', dir: 'ltr' },
  { code: 'pt', tag: 'pt', name: 'Português', dir: 'ltr' },
  { code: 'de', tag: 'de', name: 'Deutsch', dir: 'ltr' },
  { code: 'fr', tag: 'fr', name: 'Français', dir: 'ltr' },

const COUNTRIES = {
  id: 'ID',
  ms: 'MY BN',
  ru: 'RU BY KZ KG',
  zh: 'CN',
  'zh-hk': 'HK MO TW',
  ko: 'KR',
  ja: 'JP',
  ar: 'SA AE EG QA KW BH OM JO IQ LB MA DZ TN LY SD YE SY PS MR',
  fa: 'IR AF',
  es: 'ES MX AR CO CL PE VE EC GT CU BO DO HN PY SV NI CR PA UY PR',
  pt: 'BR PT AO MZ',
  de: 'DE AT CH LI',
  fr: 'FR MC',
  it: 'IT SM',
  pl: 'PL',
};

export const COUNTRY_TO_LOCALE = Object.fromEntries(
  Object.entries(COUNTRIES).flatMap(([code, list]) => list.split(' ').map((cc) => [cc, code])),
);

/** @param {string | null | undefined} cc */
export const localeForCountry = (cc) =>
  (typeof cc === 'string' && COUNTRY_TO_LOCALE[cc.toUpperCase()]) || DEFAULT_LOCALE;

/** @param {string} pathname */
const firstSegment = (pathname) => (pathname.split('?')[0].split('#')[0].split('/')[1] ?? '');

/** The locale named by a path's whole first segment, else English. @param {string} pathname */
export const localeFromPath = (pathname) => {
  const first = firstSegment(pathname);
  return isLocale(first) ? first : DEFAULT_LOCALE;
};

/** The path without its locale prefix; always starts with a slash. @param {string} pathname */
export const stripLocale = (pathname) => {
  const first = firstSegment(pathname);
  if (!isLocale(first)) return pathname || '/';
  const rest = pathname.slice(1 + first.length);
  return rest === '' || rest.startsWith('?') || rest.startsWith('#') ? `/${rest}` : rest;
};

/** Paths the app does not serve as pages; never prefixed. */
export const UNPREFIXED = /^\/(api|ws|_next|viewing|rpc|cdn-cgi|\.well-known)(\/|$)/;

/**
 * A root-relative page path in a locale: "/blocks" -> "/ru/blocks". Absolute URLs, anchors,
 * the API, static files and anything with an extension come back unchanged.
 * @param {string} locale @param {string} path
 */
export const localizePath = (locale, path) => {
  if (!path.startsWith('/') || path.startsWith('//')) return path;
  if (UNPREFIXED.test(path)) return path;
  if (/\.[a-z0-9]{2,5}(\?|#|$)/i.test(path)) return path;
  const bare = stripLocale(path);
  if (locale === DEFAULT_LOCALE) return bare;
  return bare === '/' || bare.startsWith('/?') || bare.startsWith('/#')
    ? `/${locale}/${bare.slice(1)}`
    : `/${locale}${bare}`;
};
```

```js
// frontend/src/i18n/routing.js
// What the middleware does with a request, as a pure function the tests can call.
import { DEFAULT_LOCALE, LOCALES, UNPREFIXED, isLocale, localeForCountry, localizePath, stripLocale } from './locales.js';

const HAS_EXTENSION = /\.[a-z0-9]{2,5}$/i;

/**
 * @param {{ pathname: string, search: string, cookie: string | null | undefined, country: string | null | undefined }} req
 * @returns {{ kind: 'next' } | { kind: 'redirect', to: string, status: 302 | 308 } | { kind: 'rewrite', to: string }}
 */
export function decide({ pathname, search, cookie, country }) {
  const q = search || '';
  if (UNPREFIXED.test(pathname) || HAS_EXTENSION.test(pathname)) return { kind: 'next' };

  const first = pathname.split('/')[1] ?? '';
  if (first === DEFAULT_LOCALE) {
    return { kind: 'redirect', to: stripLocale(pathname) + q, status: 308 };
  }
  if (isLocale(first)) return { kind: 'next' };

  if (pathname === '/') {
    const chosen = isLocale(cookie) ? cookie : localeForCountry(country);
    if (chosen !== DEFAULT_LOCALE) return { kind: 'redirect', to: localizePath(chosen, '/') + q, status: 302 };
  }
  return { kind: 'rewrite', to: `/${DEFAULT_LOCALE}${pathname === '/' ? '' : pathname}${q}` };
}

/** The `Link` header: every language's URL for one unprefixed path, then x-default. */
export function alternatesHeader(origin, barePath) {
  const entries = LOCALES.map(
    (l) => `<${origin}${localizePath(l.code, barePath)}>; rel="alternate"; hreflang="${l.tag}"`,
  );
  entries.push(`<${origin}${localizePath(DEFAULT_LOCALE, barePath)}>; rel="alternate"; hreflang="x-default"`);
  return entries.join(', ');
}

/** The first address of X-Forwarded-For, or null. @param {string | null | undefined} xff */
export function clientIp(xff) {
  if (!xff) return null;
  const first = xff.split(',')[0].trim();
  return first === '' ? null : first;
}
```

```js
// frontend/src/i18n/geoip.js
// The visitor's country from an offline copy of DB-IP Country Lite, read once into memory.
// Nothing is stored and nothing leaves the process (privacy page, "IP address").
import { readFileSync } from 'node:fs';
import { Reader } from 'mmdb-lib';

/** @param {string | undefined} path @returns {{ country: (ip: string) => string | null } | null} */
export function openCountryDb(path) {
  if (!path) return null;
  let reader;
  try {
    reader = new Reader(readFileSync(path));
  } catch {
    return null;
  }
  return {
    country(ip) {
      if (!ip) return null;
      try {
        const r = reader.get(ip);
        const cc = r?.country?.iso_code;
        return typeof cc === 'string' && cc.length === 2 ? cc.toUpperCase() : null;
      } catch {
        return null;
      }
    },
  };
}

let loaded = false;
/** @type {ReturnType<typeof openCountryDb>} */
let db = null;

/** The process-wide database from GEOIP_DB, opened on first use; one log line either way. */
export function countryDb() {
  if (!loaded) {
    loaded = true;
    const path = process.env.GEOIP_DB;
    db = openCountryDb(path);
    console.log(db ? `i18n: country database loaded from ${path}` : 'i18n: no country database (GEOIP_DB unset or unreadable); every first visit is English');
```

```ts
// frontend/src/middleware.ts
// English unprefixed, fifteen languages prefixed, the root by cookie then country, and an
// hreflang Link header on every page. The rules are src/i18n/routing.js (tested); this file only
// talks to Next. Node runtime so the country database can be read from disk.
import { NextResponse, type NextRequest } from 'next/server';
import { decide, alternatesHeader, clientIp } from '@/i18n/routing';
import { countryDb } from '@/i18n/geoip';
import { stripLocale } from '@/i18n/locales';

export const config = {
  runtime: 'nodejs',
  matcher: ['/((?!_next/|api/|ws|viewing/|rpc).*)'],
};

const ORIGIN = 'https://randscan.org';

export function middleware(req: NextRequest) {
  const { pathname, search } = req.nextUrl;
  const cookie = req.cookies.get('lang')?.value ?? null;
  const country =
    pathname === '/' && !cookie
      ? countryDb()?.country(clientIp(req.headers.get('x-forwarded-for')) ?? '') ?? null
      : null;

  const d = decide({ pathname, search, cookie, country });
  let res: NextResponse;
  if (d.kind === 'redirect') {
    res = NextResponse.redirect(new URL(d.to, req.url), d.status);
  } else if (d.kind === 'rewrite') {
    res = NextResponse.rewrite(new URL(d.to, req.url));
  } else {
    res = NextResponse.next();
  }
  if (d.kind !== 'redirect' && !/\.[a-z0-9]{2,5}$/i.test(pathname)) {
    res.headers.set('Link', alternatesHeader(ORIGIN, stripLocale(pathname)));
    res.headers.set('Vary', 'Cookie');
  }
  return res;
}
```

```js
// frontend/src/i18n/merge.js
/** Deep merge: the translation over English. Only keys English has survive; a wrong type,
 *  an empty string or a missing value falls back to English; arrays merge element-wise. */
export function merge(base, over) {
  if (over === undefined || over === null) return base;
  if (Array.isArray(base)) {
    if (!Array.isArray(over)) return base;
    return base.map((item, i) => (i < over.length ? merge(item, over[i]) : item));
  }
  if (base !== null && typeof base === 'object') {
    if (over === null || typeof over !== 'object' || Array.isArray(over)) return base;
    const out = {};
    for (const k of Object.keys(base)) out[k] = merge(base[k], over[k]);
    return out;
  }
  if (typeof over !== typeof base) return base;
  if (typeof over === 'string' && over === '') return base;
  return over;
}
```

```js
// frontend/src/i18n/rich.js
// A message with a little markup — <a href>, <code>, <strong>, <em>, <br/> — as a token tree
// React can render without innerHTML. Anything that is not one of those tags is text.
const TAG = /<(a)\s+href="([^"]*)">|<(code|strong|em)>|<\/(a|code|strong|em)>|<br\s*\/?>/g;

export function fill(s, vars = {}) {
  return s.replace(/\{(\w+)\}/g, (m, k) => (k in vars ? String(vars[k]) : m));
}

export function tokenize(s) {
  const root = { children: [] };
  const stack = [root];
  let last = 0;
  const text = (t) => { if (t) stack[stack.length - 1].children.push({ type: 'text', text: t }); };
  for (const m of s.matchAll(TAG)) {
    text(s.slice(last, m.index));
    last = m.index + m[0].length;
    if (m[1]) { const node = { type: 'a', href: m[2], children: [] }; stack[stack.length - 1].children.push(node); stack.push(node); }
    else if (m[3]) { const node = { type: m[3], children: [] }; stack[stack.length - 1].children.push(node); stack.push(node); }
    else if (m[4]) { if (stack.length > 1) stack.pop(); }
    else { stack[stack.length - 1].children.push({ type: 'br' }); }
  }
  text(s.slice(last));
  return root.children;
}
```

```tsx
interface Ctx { locale: string; tag: string; dir: 'ltr' | 'rtl'; messages: Messages }
const I18nContext = createContext<Ctx | null>(null);

export function I18nProvider({ locale, messages, children }: { locale: string; messages: Messages; children: ReactNode }) {
  const info = localeInfo(locale);
  const value = useMemo(() => ({ locale: info.code, tag: info.tag, dir: info.dir, messages }), [info, messages]);
  return <I18nContext.Provider value={value}>{children}</I18nContext.Provider>;
}

function ctx(): Ctx {
  const c = useContext(I18nContext);
  if (!c) throw new Error('useT/useLocale outside I18nProvider');
  return c;
}

export function useLocale() {
  const { locale, tag, dir } = ctx();
  return { code: locale, tag, dir };
}

const lookup = (m: unknown, key: string): unknown =>
  key.split('.').reduce<unknown>((o, k) => (o && typeof o === 'object' ? (o as Record<string, unknown>)[k] : undefined), m);

export function useT() {
  const { messages, locale } = ctx();
  const t = useCallback((key: string, vars?: Record<string, string | number>) => {
    const v = lookup(messages, key);
    if (typeof v !== 'string') {
      if (process.env.NODE_ENV !== 'production') console.warn(`i18n: missing key ${key}`);
      return key;
    }
    return vars ? fill(v, vars) : v;
  }, [messages]);
  const get = useCallback(<T,>(key: string): T => lookup(messages, key) as T, [messages]);
  const rich = useCallback((key: string, vars?: Record<string, string | number>): ReactNode => (
    <Rich text={t(key, vars)} locale={locale} />
  ), [t, locale]);
  return { t, get, rich };
}

  const { locale } = ctx();
```

```js
// frontend/scripts/i18n/translate.mjs
// Translate src/i18n/messages/en.json into every other locale with `claude -p`, ~1,500 words a
// call, N calls in parallel, keeping {placeholders}, <tags>, identifiers and the glossary intact.
// Re-runnable: a key whose English text has not changed since the locale file was written is kept.
//   node scripts/i18n/translate.mjs            # all locales, changed keys only
//   node scripts/i18n/translate.mjs ru ja      # some locales
//   FORCE=1 node scripts/i18n/translate.mjs    # everything again
import { readFileSync, writeFileSync, existsSync, mkdirSync } from 'node:fs';
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';
import { createHash } from 'node:crypto';
import { LOCALES } from '../../src/i18n/locales.js';

const run = promisify(execFile);
const ROOT = new URL('../../', import.meta.url).pathname;
const MSG = `${ROOT}src/i18n/messages/`;
const STAMP = `${ROOT}src/i18n/messages/.source-hashes.json`; // key -> sha1 of the English text at translation time
const GLOSSARY = readFileSync(new URL('./glossary.txt', import.meta.url), 'utf8').trim();
const SKIP = /(^|\.)(href|url|code|symbol|id|slug|hash|address|example|method)$/;
const PARALLEL = Number(process.env.PARALLEL || 6);
const MODEL = process.env.MODEL || 'sonnet';

const REGISTER = {
  ru: 'Russian', zh: 'Simplified Chinese (Mandarin, mainland conventions)', 'zh-hk': 'Traditional Chinese as written in Hong Kong',
  ko: 'Korean', id: 'Indonesian', ms: 'Malay (Malaysia; not Indonesian wording)', ja: 'Japanese', ar: 'Modern Standard Arabic',
  fa: 'Persian (Farsi)', es: 'Spanish (neutral, Latin America-leaning)', pt: 'Portuguese (neutral, Brazilian-leaning)',
  de: 'German', fr: 'French', it: 'Italian', pl: 'Polish',
};

const flat = (o, p = '', out = {}) => { for (const [k, v] of Object.entries(o)) { const key = p ? `${p}.${k}` : k; if (v && typeof v === 'object') flat(v, key, out); else out[key] = v; } return out; };
const unflat = (f) => { const o = {}; for (const [k, v] of Object.entries(f)) { const parts = k.split('.'); let c = o; for (let i = 0; i < parts.length - 1; i++) { const p = parts[i]; const nextIsIndex = /^\d+$/.test(parts[i + 1]); c[p] ??= nextIsIndex ? [] : {}; c = c[p]; } c[parts.at(-1)] = v; } return o; };
const sha = (s) => createHash('sha1').update(s).digest('hex');
const marks = (s) => [...String(s).matchAll(/\{(\w+)\}|<(a|code|strong|em)\b|<br/g)].map((m) => m[0].replace(/\s.*$/, '')).sort().join(' ');

const en = flat(JSON.parse(readFileSync(`${MSG}en.json`, 'utf8')));
const stamps = existsSync(STAMP) ? JSON.parse(readFileSync(STAMP, 'utf8')) : {};
const wanted = process.argv.slice(2).length ? process.argv.slice(2) : LOCALES.map((l) => l.code).filter((c) => c !== 'en');

function chunks(entries, words = 1500) {
  const out = []; let cur = []; let n = 0;
  for (const e of entries) { const w = String(e[1]).split(/\s+/).length; if (n + w > words && cur.length) { out.push(cur); cur = []; n = 0; } cur.push(e); n += w; }
  if (cur.length) out.push(cur);
  return out;
}

async function translateChunk(code, entries, attempt = 1) {
  const prompt = `You are translating the user interface of RandScan, the block explorer of the Rand Protocol, into ${REGISTER[code]}.
Return ONLY a JSON object mapping each key to its translation, nothing else. Rules:
- Keep every {placeholder}, every <a href="…">, <code>, <strong>, <em> and <br/> tag exactly where it is, with the same content inside tags that are identifiers.
- Keep in English, untranslated: ${GLOSSARY}; every identifier, field name, RPC method, CLI flag, file name, hex string and number.
- Technical register, plain and short, as a competent native UI writer would phrase it. No added explanations. Keep punctuation conventions of the language.
- A value that is already only a brand name, a symbol or a number stays identical.
Input JSON:
${JSON.stringify(Object.fromEntries(entries), null, 1)}`;
  const { stdout } = await run('claude', ['-p', '--model', MODEL, '--output-format', 'text'], { input: prompt, maxBuffer: 1 << 26 });
  const m = stdout.match(/\{[\s\S]*\}/);
  let out;
  try { out = JSON.parse(m ? m[0] : stdout); } catch { out = null; }
  const bad = !out ? entries.map((e) => e[0]) : entries.filter(([k, v]) => typeof out[k] !== 'string' || out[k].trim() === '' || marks(v) !== marks(out[k])).map((e) => e[0]);
  if (bad.length && attempt < 3) {
    console.warn(`${code}: ${bad.length} keys failed checks, retrying (${attempt + 1})`);
    const again = await translateChunk(code, entries.filter((e) => bad.includes(e[0])), attempt + 1);
    return { ...(out ?? {}), ...again };
  }
  if (bad.length) { for (const k of bad) delete out?.[k]; console.error(`${code}: gave up on ${bad.join(', ')}`); }
  return out ?? {};
}

async function pool(items, n, fn) { const q = [...items]; const res = []; await Promise.all(Array.from({ length: n }, async () => { while (q.length) { const it = q.shift(); res.push(await fn(it)); } })); return res; }

for (const code of wanted) {
  const file = `${MSG}${code}.json`;
  const existing = existsSync(file) ? flat(JSON.parse(readFileSync(file, 'utf8'))) : {};
  const st = (stamps[code] ??= {});
  const todo = Object.entries(en).filter(([k, v]) => typeof v === 'string' && v.trim() !== '' && !SKIP.test(k) && (process.env.FORCE || typeof existing[k] !== 'string' || st[k] !== sha(v)));
  const keep = Object.fromEntries(Object.entries(en).filter(([k]) => SKIP.test(k) || typeof en[k] !== 'string').map(([k, v]) => [k, v]));
  console.log(`${code}: ${todo.length} of ${Object.keys(en).length} keys to translate`);
  const results = await pool(chunks(todo), PARALLEL, (c) => translateChunk(code, c));
  const merged = { ...existing, ...keep };
  for (const r of results) for (const [k, v] of Object.entries(r)) { merged[k] = v; st[k] = sha(en[k]); }
  for (const k of Object.keys(merged)) if (!(k in en)) delete merged[k];
  const ordered = Object.fromEntries(Object.keys(en).map((k) => [k, merged[k] ?? en[k]]));
  writeFileSync(file, JSON.stringify(unflat(ordered), null, 2) + '\n');
  writeFileSync(STAMP, JSON.stringify(stamps, null, 1) + '\n');
  console.log(`${code}: written`);
}
```
